# Discord Cleanup Script

Discordアカウントが乗っ取られた際に、乗っ取り中に送信された自分のメッセージや作成された不正なスケジュールイベントを検索・削除するための復旧用スクリプトです。標準ライブラリのみで動作するため、iPhoneのa-Shellなどでもそのまま実行できます。

## 前提条件(必ず先に実施すること)

1. パスワードを変更し、Discordアプリ設定 > マイアカウント > 「すべてのデバイスからログアウト」を実行する
2. 二要素認証(2FA)を有効化する
3. 上記実施後に**新しく**取得した自分のユーザートークンを使う(古いトークンは乗っ取り犯のセッションと同じ扱いになるため使わない)

## トークンの取得方法

PC(Mac/Windows)のブラウザでDiscordにログインし、開発者ツール(F12)のNetworkタブでリクエストヘッダの `authorization` の値をコピーします。取得後は安全な場所に一時保管し、使用後は削除してください。

## セットアップ

```bash
export DISCORD_TOKEN="新しいトークンをここに"
```

## GUI版 (Tkinter)

コマンドライン操作なしで使いたい場合は、GUI版が使えます(Python標準のTkinterのみで動作、追加インストール不要)。

```bash
python discord_cleanup_gui.py
```

起動したウィンドウで以下を設定して実行します。

- **Discordトークン**: 入力欄はデフォルトで伏字表示(「表示」チェックで平文表示に切り替え可能)
- **対象範囲**: 「サーバー+DM」「サーバーのみ」「DMのみ」から選択(CLI版の`--scope`相当)
- **開始日/終了日**: 任意。CLI版と同じくUTC基準
- **繰り返し回数(passes) / パス間待機秒数**: CLI版の`--passes`/`--wait-between-passes`と同じ
- **「一覧表示のみ」ボタン**: 削除せず対象を確認(CLI版の`--list`相当)
- **「削除を実行」ボタン**: 確認ダイアログの後に実際に削除(CLI版の`--delete`相当)

進行状況・結果はウィンドウ下部のログ欄にリアルタイム表示されます。トークンはメモリ上でのみ扱われ、ファイルには保存されません。

## 使い方

まず`--list`で削除対象を確認します(削除は実行されません)。

```bash
python discord_cleanup.py --list --start 2026-09-01 --end 2026-09-10
```

内容に問題なければ`--delete`で実際に削除します。

```bash
python discord_cleanup.py --delete --passes 3 --wait-between-passes 30 --start 2026-09-01 --end 2026-09-10
```

## 引数一覧

| 引数 | 必須/任意 | 説明 |
|---|---|---|
| `--list` | どちらか必須 | 削除対象を一覧表示するだけ(削除しない) |
| `--delete` | どちらか必須 | 対象を実際に削除する |
| `--start YYYY-MM-DD` | 任意 | この日付以降のメッセージ/イベントのみ対象(UTC基準) |
| `--end YYYY-MM-DD` | 任意 | この日付まで(23:59:59 UTC)のメッセージ/イベントのみ対象 |
| `--scope {all,guilds,dms}` | 任意(既定all) | `guilds`=サーバーのみ、`dms`=DMのみ、`all`=両方 |
| `--passes N` | 任意(既定1) | 検索→削除をN回繰り返す。検索インデックスの反映ラグで1回目に見つからなかった分を後続パスで拾う |
| `--wait-between-passes 秒数` | 任意(既定30) | パス間の待機秒数 |

`--start`/`--end`は日本時間ではなくUTC基準です。日本時間との境界をまたぐ場合は余裕を持って1日多めに指定することを推奨します。

## 検出範囲について

- 通常のDM一覧(`/users/@me/channels`)は自分がクライアントで「開いている」DMしか返しません。
  相手が一度もDMを開いていない、または送信後にDMを閉じた場合は、このチャンネルが一覧に出ず
  検出漏れになる可能性があります(Discordの公開APIには、これを横断的に検索する手段が
  ないため、現状これは既知の制限事項です)。
- 削除は並列(既定6並列)で実行し、レート制限(429)はAPI側の指示に従って自動待機・再試行します。

## 注意事項

- ユーザートークンでの自動操作はDiscord利用規約上グレー〜禁止領域です。本人による不正送信物の復旧削除という目的の一時利用として、自己責任で使用してください。
- 使用後はトークンとログを安全に破棄してください。
- レートリミットを尊重するため削除間隔を空けています。件数が多いと時間がかかります。
- サーバー管理者が既に削除したメッセージ/イベントは「既に削除済み」として成功扱いになります。
